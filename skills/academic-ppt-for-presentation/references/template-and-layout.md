# 模板、排版与公式规范

本文件统一维护三种模式适用的视觉规则。可编辑性、语义一致、自然阅读、数学排版和实际渲染检查是共同要求。用户最新明确要求优先；未指定的部分遵循所选模板或参考。内置蓝白模板的字号、段落样式、章节标题和导航规范用于工作汇报与 Paper Reading；论文或项目申请书配图按目标文档的栏宽、版心、图内层级和最终放置尺寸设计，不强加汇报页的正文层级、字号、章节结构或画布比例。

## 内置模板：默认继承，有证据地有限调整

工作汇报或 Paper Reading 使用内置模板时，先复制 `assets/reference.pptx`，选择、复制、重排或省略源页。必须保留源文件的画布、母版、版式、主题和继承链。模板样例文字可以替换，无用样例对象可以删除；不能从空白文档重新画“蓝白风格”。先读 [保留格式的编辑与校验流程](template-preservation.md)；需要根据实际效果调整时，再按 [受控视觉微调](controlled-adjustments.md) 执行。

下表是当前资产的识别索引，**不是供程序重新设置样式的参数表**。最终以实际源对象的完整格式为准；更换用户指定模板时从新源提取，不套此表。

| 角色与源位置（页序 / shape ID） | 当前模板的识别特征 |
| --- | --- |
| 封面标题：1 / 4 | 微软雅黑，44 pt，蓝色 `0000FF`，居中、单倍行距 |
| 封面姓名日期：1 / 22 | 微软雅黑，24 pt，字符间距 3 pt，居中、1.2 倍行距、段后 12 pt；颜色保持继承 |
| 页面大标题：2–9 / 4 | Arial，28 pt，加粗，`044875`，字符间距 3 pt |
| 正文一级：2–9 / 5 的一级段落 | 微软雅黑，28 pt，加粗，黑色，1.5 倍行距，段前/后 0 pt，两端对齐 |
| 正文二级：2–9 / 5 的二级段落 | 微软雅黑，24 pt，黑色，单倍行距，段前/后 0 pt，两端对齐 |
| 导航、页码、来源、辅助标签 | 各自复制对应源对象；存在混合字体、颜色和继承值，不统一成正文样式 |

- 同一角色默认继承字体（含 Latin / East Asian / Complex Script）、字号、色值或主题色引用、加粗/斜体、字符间距、下划线和上/下标。字号、必要的字体及颜色调整只能按受控流程逐项登记；不能把所有字体统一成微软雅黑，也不能把大标题套成正文标题。
- 段落默认继承源格式；只有段前/后和行距可依受控流程有限调整，层级、对齐、项目符号、缩进和制表位仍保留。正文一级的原生项目符号是 Wingdings `p`，二级是 Wingdings `Ø`；不能用可见的 `■`、`>`、`•` 等文本字符近似替换。
- `bodyPr`、`lstStyle` 以及母版/版式/主题保持不变；`pPr/defRPr`、各 run 的 `rPr` 和 `endParaRPr` 只允许受控规则中逐项登记的属性变化，其余保留。缺少显式属性也是源格式的一部分，不能把 `None` 当作应补写的库默认值；继承值的局部覆盖需要先解析有效值并补充等价专项校验，不能假定随附脚本已支持。
- 保留原 `spAutoFit`（形状随文字扩大）等设置；不得引入 `normAutofit` 或调用自动缩字。缺字或字体替代须先核实实际渲染，并优先使用具备原字体的环境；原字体方案不适用时才按受控流程做必要替换。颜色仅为修复实际低对比而调整，从源模板色板选择并保留语义角色，不能静默换字体或重配色。
- 内容过满时先删重复、缩短文案、调整内容区布局；仍有可定位问题时才按受控流程考虑段距、行距、字号。不得压缩字距、修改框内边距或横向压缩文字来塞内容。超出微调预算先换合适源页型或拆页；用户固定页数时在该范围内组织，不擅自改页数。若全部内容与指定页数仍无法兼容，说明冲突并保留可完成的部分。

## 标题、导航与阅读顺序

- 页面大标题标明当前讲述的部分，例如 `Motivation`、`Methods`、`实验介绍与分析`；同一连贯章节连续复用，不让每页变成孤立主题。
- 页面内一级正文标题概括该页重点，通常一个、必要时两个；复用源一级段落，不把每个定义、步骤或项目都升级成标题。
- 保留导航对象的普通/选中状态样式，按叙事需要选择对应源页；不强制加入五张章节导航。方法较长时，可先用原论文流程图或简洁总览建立关系，再展开细节。
- 需要结论框时复用模板已有同角色对象；没有适合对象时使用普通模板正文表达，不擅自新增蓝底白字、强调色或新的字体层级。

## 文本框、段落与间距

- 原文本框和真实段落优先复用；连续的正文与列表保持原有层级组织，不一行一个文本框。新增段落复制同层级源段落，新增文本对象复制相同角色源对象，不靠新建对象的默认样式。
- 同一段正文自然换行，独立列表项使用独立段落。不能通过插入空段落、连续空格或大量手动换行模拟缩进和段间距。
- 图片或公式使用源页可用的图文区域；实际渲染出现布局问题时，可调整内容区域对象的位置及外部边界，记录问题与调整结果。保持模板装饰和框内边距；若还需改文字或段落属性，另外按受控流程登记，不覆盖原内容来另起一套设计。
- 标题与正文、各层级之间的间距从源段落和源布局出发。实际出现拥挤、分组不清或段距失衡时，按受控流程验证最小修正；“视觉上更合理”不能替代具体问题和前后对照，也不能据此修改母版或版式。

## 公式与数学排版

- 汇报中的公式默认作为独立 SVG/图片内容资产，不改变相邻普通文本的 run 格式。用户要求原生可编辑公式时，保留数学对象并补充专项格式检查；随附脚本对未支持的数学对象不会返回通过，不能改基准或忽略报错来绕过。科研绘图中的简单表达式可用 Office 原生公式，注意基线与周围标签协调。
- 复杂或独立展示公式优先从 LaTeX 编译为紧裁切的 SVG/PDF 或清晰透明图片，保留工作用 LaTeX 源码。若用户明确要求图片/SVG 或禁止原生公式，按该要求执行。
- 数学字体优先与 Times New Roman 风格一致；需要完整数学字形时使用相容的 Times 风格数学字体。不要用普通文本加手画分数线来模拟排版。
- `exp`、`log`、`min`、`max`、`Pr` 等算子与文字标签使用正体，变量按数学惯例处理。编译时使用 `\exp`、`\log`、`\mathrm{}`、`\text{}` 等恰当命令。
- 公式大小与正文协调，24 pt 正文旁可用约 20–26 pt 的视觉尺度作为起点，不为填满图片框而放大。检查上下标、留白、行内基线、算子字体和公式与解释的对应关系。
- 核对公式来源；区别原文公式、等价改写和报告者补充说明。只在有助理解时使用公式，不追求每页都有，也不为简短而删掉必要机制。

## 图表与引用

- 优先使用真实论文图表和实际实验结果。保留解释证据所需的坐标、图例、单位、面板标识和实验条件；不得改变数据来改善视觉效果。
- 当前正在介绍的论文不在每页底部重复列名，也不添加“本页解释什么”的例行页脚。精确的章节、公式、图表、页码和来源路径放在讲者备注 `[Sources]` 中。
- 只有引用另一篇论文时显示 `<论文名>(会议/期刊名缩写 年份)`。会议信息需核实；仅能确认预印本时使用 `arXiv 年份`。一篇论文进入自己的讲解部分后，不再作为每页重复的外部引用。
- 保留必要的归属或许可信息，不把“不加例行页脚”解释为删除必需的来源声明。

## 版式验收

汇报先渲染定位问题；有调整时按 [受控视觉微调](controlled-adjustments.md) 保存前后证据。再按 [保留格式的编辑与校验流程](template-preservation.md) 检查最终 PPTX，仅放行已登记且符合规则的变更。实际检视最终每页，并与源页及调整前画面对照字体、颜色、字号、段落、导航、自然换行、图例、公式、遮挡和越界；机器校验不能代替视觉判断。科研绘图按其目标尺寸验收，不运行汇报模板格式校验。检查编辑对象的组织方式，而不仅是最终截图；确认整页没有被展平为图片。页面结构变化后检查页码、章节名称和指代的一致性。
